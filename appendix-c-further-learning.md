# Appendix C — Resources, Ranked

Everything linked in the course, gathered and sorted by how much I'd actually recommend it. **Free unless marked 💵.**

The list is long. That's a menu, not an assignment. Pick the ⭐ items first.

## When you're stuck

1. **Read the error message.** Slowly. All of it.
2. **The official docs.** Almost always better than the blog post that ranks above them.
3. **The library's GitHub issues.** Search closed ones too — someone hit this in 2023.
4. **Ask Claude to diagnose, not to fix** (Appendix A, Pattern 9).
5. **Stack Overflow** — check the date. A 2014 answer about JavaScript is probably obsolete.
6. **Read the source.** It's in `node_modules`. This is allowed, and it's a superpower.
